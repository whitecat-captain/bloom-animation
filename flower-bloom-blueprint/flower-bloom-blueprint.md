## 0. 一句话原理（先建立心智模型）

> **整朵花没有任何「花瓣模型」。它是一张平面网格，被一个着色器实时折叠成花瓣；
> 再用叶序数学把同一片花瓣复制几十次摆成螺旋；最后用一个 `0→1` 的数字像波一样
> 从外圈扫到花心，让每片花瓣在不同时刻打开 —— 这就是绽放。**

记住三个关键词：**一张网格、一段着色器、一个数字。**

---

## 技术栈（约束 Claude 用这套）

- **Three.js**（WebGL）。**全程不加载任何 3D 模型文件**，花全部由数学生成。
- 整朵花 = **1 个 `InstancedMesh` + 1 个 `ShaderMaterial`**（顶点着色器负责所有形变，片元着色器负责上色）。
- 控制面板 = 原生 `<input type="range">` 滑块 + 按钮（参数面板见第 7 节，仿 `/social` 的卡片式联动）。

---

## 五层结构（施工主干 · 自下而上盖）

```
  层5  风 & 不完美 ····· value-noise 让它像活的（最后做）
  层4  实例化 ········· 1 次 draw call 画完所有花瓣
  层3  绽放波前 ······· 一个数字 bloom 0→1 变成一道波        ← 动画的核心
  层2  叶序螺旋 ······· 黄金角 137.5° 把花瓣摆成穹顶
  层1  单片花瓣 ······· 平面网格被着色器卷成花瓣            ← 形状的核心
  层0  场景 ··········· 相机 / 黑背景 / 茎与叶
```

每一层只依赖它下面的层。建议按 **层1 → 层2 → 层3 → 层4 → 层5** 的顺序施工。

---

## 层 1 · 单片花瓣 = 平面 + 着色器

**几何**：`PlaneGeometry(1, 1, 24, 64)` —— 一张细分平面。
约定 UV：`uv.x` = 横向（0..1，宽度方向），`uv.y` = 纵向（0..1，从花瓣基部到尖端）。

**在顶点着色器里两步把平面变成花瓣：**

**① 宽度（决定胖瘦）** —— 沿长度方向，用 4 个控制宽度 `[w0,w1,w2,w3]` 经 **Catmull-Rom 样条**插值，得到每个高度 `v` 处的轮廓半宽。基部窄、中段宽、尖端收。

**② 卷曲（决定卷/开）** —— 沿花瓣「脊柱」**积分曲率**，把平直的脊柱卷起来：

```glsl
float ang = 0.0;          // 当前朝向角
vec2  spine = vec2(0.0);  // 脊柱坐标
for (int i = 0; i < N; i++) {          // N≈24 步，沿 v 走
  float s = (i + 0.5) / N;             // 当前归一化弧长
  float density = curvatureConcentration(s);  // 曲率集中度：s^bias 的导数，越靠尖端越弯
  float curl = mix(curlClosed, curlOpen, openness(s, bloomLocal)); // ← 绽放在这里介入
  ang   += curl * density * ds;         // 累积转角
  spine += vec2(cos(ang), sin(ang)) * ds; // 沿当前朝向前进一步
}
```

- `curlClosed ≈ 1.7`（合拢时卷成筒）、`curlOpen ≈ -0.35`（开放时微微外翻）。
- 再叠加细节：`cup`（横向杯状弧度）、`sideCurl`（横向卷边）、`waveAmp`（边缘波浪）、`asym`（轻微不对称）。

> 🔑 **核心洞察**：同一套积分公式，只要把 `curl` 从 `curlClosed` 渐变到 `curlOpen`，
> 花瓣就从「卷」变「开」。**绽放，本质上就是连续地改这一个 `curl` 数。**

---

## 层 2 · 叶序螺旋 = 把花瓣摆成穹顶

给第 `i` 片花瓣（共 `n` 片），令 `u = i / (n-1)`（**`u=0` 是花心，`u=1` 是最外圈**）：

```js
const a = i * 137.5 * Math.PI / 180;      // 黄金角：每片比上一片多转 137.5°
const r = radius * Math.pow(u, radiusBias); // 半径沿幂曲线向外
const y = height * Math.pow(u, heightBias); // 花托是个圆顶
dummy.position.set(Math.sin(a) * r, height - y, Math.cos(a) * r);
dummy.rotation.y = a;                       // 绕中心轴朝外
// 外倾角（越外圈越平展）存进实例属性 aTilt（见层4）
```

> 🔑 **为什么是 137.5°**：黄金角是无理数，花瓣永远不会排成直线「辐条」，
> 于是紧密无缝地填满圆面。换成 90°/120°/144° 会立刻看到辐条和空隙。

**对照组（教学用）**：把「向外推」关掉，改用同心圆环（中心 1 片，外面 6、12、18… 片均匀排）
= 故意「机械、太整齐」的错误排法，用来反衬螺旋的自然。

## 层 3 · 绽放 = 一个数字变成一道波 ⭐（动画核心）

绽放进度是**一个全局数字** `bloom: 0 → 1`。**不是 36 个独立动画**，而是每片花瓣
按自己的位置，把这个数字**延迟**一点点：

```glsl
float order = 1.0 - aU;                       // 外圈 order≈0「先开」，花心 order≈1「后开」
float front = mix(-width, 1.0, uBloom);       // 波前位置：随 bloom 从 -width 扫到 1
float bloomLocal = 1.0 - clamp((order - front) / width, 0.0, 1.0); // 这片花瓣的局部开放度 0..1
```

- `width`（即 `transition`）= **波前宽度** = 「同一时刻有几片在动」。窄=逐片依次开，宽=整体一起开。
- 算出的 `bloomLocal` **回喂层 1 的 `curl`**（让花瓣打开），同时驱动：
  - **外倾角** `tilt = -aTilt * bloomLocal`（开放时向外平展）
  - **花苞层叠间隙** `shell = 1 + shellGap * aU * (1 - bloomLocal)`（合拢时各圈错开成花苞）
- **双重波前**：① 花层面（外圈先于花心，靠 `aU`）+ ② 花瓣内部（基部先于尖端展开，靠 `openness(s, …)` 里的 `propagation`）。

> 🔑 这一层就是「动画」的全部：**只要把 `bloom` 从 0 动到 1，整朵花就绽放。**
> 用一段缓动（ease-out）把 `bloom` 在约 5 秒内推到上限即可自动播放。

## 层 4 · 实例化 = 一次画完所有花瓣

整朵花 = **1 个 `InstancedMesh`**（同一几何、同一材质，`n` 个实例）。每个实例 3 个属性：

```js
flower = new THREE.InstancedMesh(geo, mat, numPetals);
geo.setAttribute("aU",    new THREE.InstancedBufferAttribute(aU,    1)); // = u，它在第几圈 / 多「老」
geo.setAttribute("aSeed", new THREE.InstancedBufferAttribute(aSeed, 1)); // 随机种子（给噪声）
geo.setAttribute("aTilt", new THREE.InstancedBufferAttribute(aTilt, 1)); // 外倾角 = outAngle * u^tiltBias
```

> 🔑 一次 `draw call` 画完几十上百片花瓣，所以可以很流畅地实时调参数。

---

## 层 5 · 风 & 不完美 = 让它像活的（最后做）

完美对称的花很假。叠加 **value-noise（值噪声）** 打破对称：

- **阵风**：一个随时间漂移的噪声场，让整朵花整体摆动（`windAmp` 强度、`windSpeed` 速度、`windHeading` 方向）。
- **每片独立的小动作**：`jitter`（位置抖动）、`waveAmp`（边缘波）、`asym`（不对称）。
- 全部按 `aSeed` 加种子 → **没有两片动得一样**。
- 风力按高度加权（`uv.y²`，越靠尖端摆得越多），且只在花瓣开放后（乘 `bloomLocal`）生效。

---

## 上色 · 扁平色调（tone shading，无需打光）

每片花瓣按**自身位置**取色：

```glsl
float closeness = (1.0 - uv.y) * 0.7 + (1.0 - aU) * 0.3;
// closeness 高（花心 + 基部）= 暖；低（外圈 + 尖端）= 冷
```

- 5 段渐变：**深蓝 → 亮蓝 → 白 → 黄 → 橙红**（冷外圈 → 热花心）。
- 颜色与绽放无关，只看位置，所以全程稳定。
- 背景纯黑 `#000`，突出花。（可留一个开关在「扁平色调」与「真实光照 Lambert+透光」间切换。）

## 层 0 · 场景（包裹这一切）

- `PerspectiveCamera(fov 40)`，从斜上方看：`position (1, 3.5, 2)`，`target (0, 1.18, 0)`。
- `OrbitControls` 可旋转查看（**禁用滚轮缩放**，把滚轮留给页面/或改为按住 ⌘ 缩放）。
- 一根略微弯曲的**茎**（`TubeGeometry` 沿 Catmull-Rom 曲线）+ 3 片**叶子**（`ShapeGeometry`），扁平绿色，与花同组一起转。

## 7. 可调参数面板（★照 `/social` 设计 —— 这是重点）

> 面板做成**卡片式**：一次显示一张卡（左右箭头切换），每张卡一组滑块 + 一个「↺ Reset」，
> **拖动即实时驱动 3D 花**。另有一条「Petals」常驻滑条随时改花瓣数。
> （**不要**照搬落地页那个 lil-gui 的几十个参数；只暴露下面这几组「重要参数」。）

| 卡片 | 参数 | 范围 | 默认 | 作用 |
|---|---|---|---|---|
| **① 折叠的花瓣** | `curl` 卷曲度 | 0 – 2 | 1.1 | 单片花瓣卷/开的程度 |
| | `widths` 宽度型 `[w0..w3]` | 0.02 – 0.42（4 个可拖点）| `[0.16, 0.28, 0.30, 0.20]` | 花瓣胖瘦轮廓 |
| **② 黄金螺旋** | `seeds / numPetals` 花瓣数 | 1 – 220 | 220 | 螺旋上的点数 |
| | `goldenAngle` 发散角 | 90 / 120 / **137.5** / 144 / 160 | 137.5 | 排列角度（137.5°最优）|
| | `outwardPush` 向外推 | 开 / 关 | 开 | 关 = 退化成同心圆环（机械感对照）|
| **③ 绽放拨盘** | `bloom` 主拨盘 | 0 – 1 | 0（播放）| 绽放总进度（动画核心）|
| | `transition` 波前宽度 | 0.05 – 1 | 0.35 | 同时有几片在动 |
| **④ 一次绘制** | `numPetals` 实例数 | 1 – 150 | 36 | 花瓣数（演示实例化）|
| **⑤ 风与噪声** | `windAmp` 风力 | 0 – 1 | 0.5 | 摆动幅度 |
| | `windSpeed` 风速 | 0 – 3 | 1 | 摆动速度 |
| **常驻条** | `Petals` | 1 – 150 | 36 | 任意卡片下都能改花瓣数 |

**底层默认值（让绽放一眼就对，供 Claude 参考）**：
`petalLen 0.95`、`curlClosed 1.7`、`curlOpen -0.35`、`cup 0.4`、`radius 0.14`、`radiusBias 1.15`、`height 0.13`、`heightBias 1.2`、`outAngle 68°`、`tiltBias 2.2`、`bloomMax 0.78`、`shellGap 0.14`。

## 8. 数据流（调一次参数发生了什么）

```
[ 拖动滑块 ]
     │
     ▼
 改一个参数 param
     │
     ├──（布局类：花瓣数 / 角度 / 半径 / 排列）→ 重建几何 buildFlower()  ← 较重，改完重建
     │
     └──（形状 / 绽放 / 风 / 颜色）────────→ 只改 shader 的 uniform   ← 很轻，逐帧自动重算
                                                   │
                                                   ▼
                            顶点着色器每帧重算每个顶点位置 → 花实时变形
```

> 施工要点：**布局参数改了要 `buildFlower()` 重建**；**形状/绽放/风参数只改 uniform，不要重建**（否则卡顿）。

## 9. 给 Claude 的施工清单（验收标准）

1. Three.js + 单个 `InstancedMesh` + `ShaderMaterial`，无外部模型。
2. **花瓣形变全部在顶点着色器**（脊柱积分卷曲 + 宽度样条）；**颜色在片元着色器**（按位置的冷暖渐变）。
3. **绽放 = 单个 `bloom` 数字 0→1**，经 `bloomLocal` 公式变成由外向内的波前。
4. **叶序排列**：黄金角 137.5° + 幂律半径/高度。
5. **第 7 节的卡片式参数面板**，滑块实时联动（布局参数重建、其余改 uniform）。
6. 默认 **36 片、137.5°**，加载后**自动播放一次绽放**，并提供「▶ Bloom」重播按钮。
7. 加上风/噪声让它自然摆动；纯黑背景。
